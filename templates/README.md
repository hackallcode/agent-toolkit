# templates

Заготовки для проекта, который подключает `agent-toolkit` сабмодулем. Сам тулкит их не использует: файлы
копируются в проект как есть и дальше живут его жизнью - обновлять их отсюда не нужно.

| Файл                | Куда копировать     | Зачем                                    |
| ------------------- | ------------------- | ---------------------------------------- |
| `AGENTS.md`         | корень проекта      | точка входа: отсылает агента в сабмодуль |
| `docs/README.md`    | `docs/README.md`    | соглашения папки требований              |
| `context/README.md` | `context/README.md` | соглашения папки рабочего контекста      |
| `gitignore`         | дописать в `.gitignore` | что из `context/` уезжает в git      |

Команды подключения - «Подключение сабмодулем» в корневом [`README.md`](../README.md).
