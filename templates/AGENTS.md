# Руководство для агентов

Инструкции для агентов подключены сабмодулем в `agents/`.

Перед работой прочитай [`agents/AGENTS.md`](agents/AGENTS.md) целиком и применяй его правила.
Пути внутри инструкций (`modes/common.md`, `scripts/…`) указаны относительно корня сабмодуля:
`modes/common.md` - это `agents/modes/common.md`.

Требования проекта - в `docs/**`, рабочий контекст - в `context/**`.
